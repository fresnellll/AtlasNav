# Code–artifact release matrix

The code repository and companion dataset are one versioned release. Code
package `0.2.x` consumes artifact schema `atlasnav_artifact_release_v2`; the
verifier rejects incompatible versions, inventory disagreement, missing files,
size drift, or SHA-256 drift.

| Research object | Public code path | Companion artifact path | Reproduction level |

| Corpus normalization / FTS | `atlasnav.corpus` | upstream corpus not redistributed | rebuild from upstream |
| Four semantic views | `atlasnav.atlas.signatures`, `atlasnav.embeddings` | `browsecomp_plus/atlas` | rebuild or frozen reuse |
| Multiplex hierarchy / bridges | `atlasnav.atlas` | same frozen Atlas directory | rebuild or frozen reuse |
| Query-adaptive Router | `atlasnav.router` | `browsecomp_plus/router/model` | exact frozen inference |

## Exact trajectory coverage

Seven BrowseComp-Plus archives contain one reported full result for each of
830 questions for:

- DeepSeek: AtlasNav, DR-DCI, raw DCI;
- ChatGPT: AtlasNav, DR-DCI, raw DCI, and the evidence-supplied
  Gold-document Reference.

Development and remainder storage shards are not public units. Each archive
contains stable per-query identities, delta tool events, canonical observations,
terminal result, and judgment. The replay command recomputes accuracy and
recorded cost for all seven packages, including the paper's `801/830` Reference
cell. Evidence Blindness and paired interface cells are recomputed where their
frozen analysis records apply.

Auxiliary frozen assets do not redistribute upstream corpora. Once a user
obtains the corresponding corpus/questions, the released Atlas, full query
vectors, and frozen Router are sufficient to rebuild the query runtime without
calling the embedding service. The release deliberately excludes provider
caches, rejected builds, duplicate runtime workspaces, and the full 2,560-D
document matrices; those matrices can be regenerated by the public build
pipeline and are not consumed after Atlas construction.

BrowseComp-Plus is the one exception to the auxiliary query-vector form: its
original full-830 raw query vectors are unavailable, so the release stores the
exact post-Router dense fused ranking. This preserves exact online route
reconstruction while remaining explicit about the unavailable earlier-stage
intermediate.

## Non-equivalent forms that remain explicit

- The exact 7,163 accepted Router training rows are unavailable. The frozen
  deployed Router is exact; corpus-only training code constructs a fresh valid
  training set. The 30,000 available rows are candidates and are never labeled
  as the final set.
- The EnterpriseRAG-Bench package contains the final frozen answers, official
  answer judgements, and official document metrics. The document metrics can
  additionally be reproduced through `atlasnav enterprise evaluate` with an
  OpenAI-compatible API; no-API frozen metric replay remains available.
- Qwen and MiMo final consolidated trajectories are unavailable in this local
  source and therefore remain summary-only.
